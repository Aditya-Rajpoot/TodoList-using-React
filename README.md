## Overview

A lightweight, fully client-side Todo List app built to practice fundamental React patterns — component state, list rendering, conditional UI, and prop-driven updates — wrapped in a clean, card-based dark UI.

## ✨ Features

- ➕ Add new tasks
- ✅ Mark individual tasks as done / undone
- 🗑️ Delete tasks
- 🎯 Mark all tasks as done in one click
- 💅 Modern, card-based dark UI
- 📱 Fully responsive design

## 🛠️ Tech Stack

- **React.js** – UI library
- **Vite** – Build tool & dev server
- **JavaScript (ES6+)**
- **CSS3**
- **uuid** – Unique task IDs
